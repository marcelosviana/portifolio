## 🏛️ Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio profissional modernizado, construído com foco em **estética corporativa minimalista, alta performance e responsividade técnica**. A arquitetura foi concebida para destacar projetos de engenharia de software de alta complexidade, métricas reais de impacto e transparência de competências.

### ⚡ Tecnologias Utilizadas
- **Estruturação Semântica:** HTML5 com acessibilidade nativa (W3C).
- **Estilização & Design System:** Tailwind CSS (Dark Mode com paleta Slate/Zinc e realces em Sky/Cyan/Emerald).
- **Interatividade & Lógica:** JavaScript puro (ES6+) — sem dependências pesadas ou frameworks complexos de build, garantindo deploy instantâneo na Vercel e GitHub Pages.
- **Tipografia:** `Inter` (UI/Corpo de texto) e `JetBrains Mono` (Termos técnicos, tags e métricas).
- **Ícones Vetoriais:** Lucide Icons.

## 🚀 Projetos Técnicos em Destaque

1. **Sistema IoT de Telemetria e Monitoramento Térmico para Cadeia de Frio**
   - **Hardware/Firmware:** ESP32, Sensores DS18B20 & DHT22, C/C++.
   - **Backend:** PHP 8, MySQL, API RESTful com autenticação via API Key.
   - **Aplicação:** Supervisão contínua em salas de vacina e câmaras de conservação de imunobiológicos.

2. **Motor Transacional de Votação em Alta Concorrência (GO Tech)**
   - **Stack:** PHP, MySQL (Travas transacionais ACID), Tokens temporários criptográficos.
   - **Impacto:** Sustentação de +45% de engajamento diário com integridade transacional e redução de 90% de riscos contra *session hijacking*.

3. **Sistema Inteligente de Segmentação de Clientes com Machine Learning**
   - **Stack:** Python, Scikit-Learn (K-Means), Pandas, Matplotlib, Análise RFV.
   - **Impacto:** Clusterização de bases comerciais com determinação matemática do K ótimo pelo Método do Cotovelo.

4. **Telemetria Fisiológica e Eventos em Tempo Real para Esports (TCC)**
   - **Stack:** Node.js, Express, SQLite3, RESTful API.
   - **Aplicação:** Ingestão de batimentos cardíacos (BPM) correlacionada a momentos críticos de partidas.

5. **Simulador de Banco Digital & POO Avançada**
   - **Stack:** Java 17, Programação Orientada a Objetos, Collections API, JUnit.
